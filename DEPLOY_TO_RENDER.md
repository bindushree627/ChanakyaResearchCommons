# Deploy Chanakya Research Commons to Render

This project is configured as a persistent Python web service on Render.

## Deploy
1. Push this folder to a GitHub repository you control.
2. In Render, choose **New + → Blueprint** and select that repository.
3. Render reads `render.yaml`. Review the service and disk costs, then approve creation.
4. Wait for the build and pre-deploy database initialization to finish.
5. Open the `onrender.com` URL shown on the Render service page.

## Notes
- The blueprint uses a persistent 2 GB disk mounted at `/app/data` so SQLite and the DuckDB warehouse survive restarts and redeploys.
- The blueprint uses the Singapore region for proximity to India.
- `SECRET_KEY` is generated by Render.
- The service is configured as a paid Starter instance because persistent disks are not available on Render's free web-service tier. Check current pricing before approving.
- The initial dataset setup may take several minutes and the first semantic-search request may download the sentence-transformers model.
- Do not commit `.env` files or real credentials.
